# 🚗 Car Rental App

A cross-platform car rental mobile application built using **Flutter** with **Clean Architecture**, **BLoC**, **Firebase**, and **Dependency Injection**.

---

## 📱 Features

- 🔐 Onboarding Flow
- 🏠 Home Page with car listings
- 📄 Car Details Page
- 🗺️ Google Maps integration for car pickup locations
- 🎞️ Animated UI elements
- ⚙️ Clean Architecture (Data, Domain, Presentation)
- 📦 State Management with BLoC
- 🔥 Firebase Integration (Firestore, Auth ready)
- 📥 Dependency Injection
